# U-Connect Implementation Plan

> **For agentic workers:** Use the subagent-driven-development workflow to carry out this plan task by task. Steps use checkbox syntax for tracking.

**Goal:** Build and verify a polished local-first U-Connect demo with explainable agent matching, persistent project/intro flows, REST tools, and an MCP server.

**Architecture:** Next.js App Router renders responsive screens and thin API handlers. Pure TypeScript domain services own seed search, matching, deterministic intent parsing, validation, and tool dispatch. A server-only JSON repository persists workflow state and feeds both REST and MCP integrations.

**Tech Stack:** Next.js App Router, TypeScript, Tailwind CSS, shadcn-style/Radix primitives, Lucide, Framer Motion, Zod, Vitest, and the official MCP TypeScript server/client SDK.

**Spec:** [2026-10-16-u-connect-design.md](../specs/2026-10-16-u-connect-design.md)

## Global Constraints

- No paid APIs, credentials, hosted database, or external runtime services.
- All members, portfolios, and opportunities are fictional demo data; do not claim external verification.
- Public profile/tool results contain no private contact details until an owner explicitly shares them after candidate acceptance.
- The `data/demo-state.json` adapter is local single-process demo storage, replaceable through the repository interface.
- The deterministic agent must call the same tool dispatcher used by REST and MCP.
- Every behavior change follows red-green-refactor: write a focused failing test, observe the expected failure, implement minimally, rerun.
- The requested 2-minute demo flow is the end-to-end acceptance path.

## File Responsibilities

- `src/lib/types.ts`, `src/lib/seed.ts`: domain contracts and fictional catalog.
- `src/lib/matching.ts`, `src/lib/agent.ts`, `src/lib/tools.ts`: pure matching, intent parsing/agent plan, and validated tool dispatch.
- `src/lib/server/store.ts`: file-backed local demo repository, state transitions, and privacy-safe snapshots.
- `src/app/api/**`: thin state, agent, tools, reset, and introduction handlers.
- `src/components/demo-provider.tsx`: client state, role switcher, API calls, and surfaced mutation states.
- `src/components/ui/**`, `src/components/shell/**`, `src/components/views/**`: reusable accessible controls, responsive app frame, and focused screen views.
- `src/app/**/page.tsx`: route entries only; each imports its view.
- `src/mcp/server.ts`: optional stdio MCP server registering the same tools.
- `tests/**`: domain, validation, store, and seed regression tests.
